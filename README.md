# CE-VAULT-SYNC

VaultSync landing page (GitHub Pages: https://rmas-ce.github.io/CE-VAULT-SYNC/).

- `index.html` — the hub. Tools, guides and tutorials are listed in the `TOOLS`, `GUIDES` and `SIMS` lists near the top of the script; update `SITE.updated` when you change something.
- `guides/` — merchandising guide PDFs and their cover `.jpg` (same file name).
- `images/` — social preview (`og-cover.png`) and tutorial posters (`sim-*.webp`).
- `tutorials/<name>/` — tap-through training simulations. Each has an `img/` folder with its screens; the page loads them one step at a time.
